X、Y 的變異數與共變數

對 N 筆 X、Y 配對資料，先算每筆的兩個離均差 Xᵢ − X̄ 與 Yᵢ − Ȳ。三個公式的分子都把兩個離均差相乘再加總，樣本公式的分母都是 N − 1。

量數分子：逐筆相乘後加總樣本公式
X 的變異數SSₓ = Σ[(Xᵢ − X̄)(Xᵢ − X̄)]sₓ² = SSₓ / (N − 1)
Y 的變異數SSᵧ = Σ[(Yᵢ − Ȳ)(Yᵢ − Ȳ)]sᵧ² = SSᵧ / (N − 1)
X、Y 的共變數SPₓᵧ = Σ[(Xᵢ − X̄)(Yᵢ − Ȳ)]Cov(X, Y) = SPₓᵧ / (N − 1)

同一個離均差乘自己就是平方，所以變異數一定大於或等於 0。共變數每筆用一個 X 離均差乘一個 Y 離均差。同號相乘為正（第一、第三象限），異號相乘為負（第二、第四象限）。有一項為 0 時，乘積就是 0。

Pearson r = Cov(X, Y) / (sₓsᵧ) = SPₓᵧ / √(SSₓ × SSᵧ)。分子與分母的 N − 1 約掉後，就得到右邊的積差和公式。

上方散布圖的原始 10 筆資料中，SSₓ = 630、SSᵧ = 352、SPₓᵧ = 367。因此 sₓ² = 70、sᵧ² ≈ 39.111、Cov(X, Y) ≈ 40.778，最後得到 r ≈ .779。

從親子身高到相關係數

1886 年，法蘭西斯・高爾頓（Francis Galton）發表親子身高研究。他把父母的身高整理成可比較的平均值，發現父母較高的一組，子女平均也偏高，但偏離全體平均的幅度通常較小。父母較矮的一組也有類似現象。這就是後來所說的向平均數迴歸（regression toward the mean）。Galton 1886 年原文

十年後，卡爾・皮爾森（Karl Pearson）把這類問題放進數學模型，發展了今日常用的積差相關係數。皇家學會還保留高爾頓為皮爾森這篇論文撰寫的審查報告。兩人的工作讓研究者能以 r 描述線性關聯，再用迴歸線回答給定 X 時，Y 的預測值是多少。Pearson 1896 年論文 · Galton 的審查報告

用兩欄的 z 分數做含截距的簡單迴歸時，預測式是 ẑᵧ = r × zₓ。例如 r = 0.6，X 比平均高 2 個標準差時，預測的 Y 比其平均高 1.2 個標準差。可到「迴歸分析」的殘差與影響點圖切換兩軸的 z 分數，直接看出這個關係。

從散布圖（scatterplot）到模型

每個點代表一個觀察單位。先看方向、彎曲、離群、觀測密度與分組，再決定是否用直線描述。觀察性調查的關聯可能受混淆變項影響，推論時須說明研究設計。

Pearson 積差相關（Pearson product–moment correlation）

將每筆 X、Y 分別減去欄平均數，乘積加總得到離均差乘積和（sum of cross-products, SP）。令 SSₓ 與 SSᵧ 為各欄離均差平方和，則 r = SP / √(SSₓSSᵧ)。同向偏離平均數使 SP 增加，反向則使 SP 減少。r 介於 −1 與 1，平移或以正數改變單位不會改變 r。若反轉其中一軸的方向，r 的正負號也會反轉。

檢定 H₀：ρ = 0 時，t = r√[(n − 2)/(1 − r²)]，df = n − 2。對獨立成對觀察、近似雙變量常態的母體，可用 t 分配求 p 值。區間採 Fisher z 轉換（Fisher z transformation）z = atanh(r)，近似標準誤為 1/√(n − 3)，在 z 尺度求區間後用 tanh 轉回。

點二系列相關（point-biserial correlation）

指定兩個互斥類別，依序編成 0 與 1，再與連續變項計算 Pearson r。若第 1 類編為 0，而第 2 類編為 1，正號代表第 2 類平均數較高；交換兩類會反轉符號，絕對值與雙尾 p 值相同。

用分母為 n 的整體標準差 σᵧ 表示時，r = (Ȳ₁ − Ȳ₀)√(pq)/σᵧ，p、q 為兩類比例。與二元虛擬變數的一元迴歸及共同變異數兩組 t 檢定具有相同的雙尾檢定結果。

相關係數怎麼讀

每個點是同一觀察單位的一對 X、Y 值。點雲向右上表示正相關，向右下表示負相關。點越集中於一條有斜率的直線，|r| 越接近 1。r 接近 0 表示線性關聯弱，仍可能有明顯彎曲或分組。若任一欄的數值全相同，該欄的標準差為 0，r 無法計算。

同一個 r 在不同樣本數下可能有不同的 p 值。解讀時一起看散布圖、r、樣本數與信賴區間。離群點可能拉高或拉低 r。觀察資料中的關聯也可能來自混淆變項，因果推論需要研究設計支持。

兩條平均線如何形成四個象限

垂直線畫在 X̄，水平線畫在 Ȳ，交點是資料中心。兩軸換成 z 分數後，這兩條線都位於 0。看每個點相對於兩條平均線的位置，就知道離均差乘積 (X − X̄)(Y − Ȳ) 的正負號。
